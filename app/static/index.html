Settings: which AI marks the work

Pick a provider, paste its key, test, save. The free tiers need no card. Keys stay in this browser and are sent to this server only with each analysis; the server never stores them.

This server has a shared, built-in API key. The access code stops outsiders from using it.

Student privacy. Free tiers usually let the provider use what you send to improve their models. Remove student names from documents, check your school's data policy, and prefer a local model or a paid plan when confidentiality matters.
